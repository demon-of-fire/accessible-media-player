# Accessible Media Player

A fully featured, screen-reader friendly media player built with Electron. Plays video and audio, with an NVDA-friendly interface, keyboard shortcuts, playlists, subtitles, picture-in-picture, audio equalizer, visualizer, snapshots, bookmarks, and more.

## Download

[Download Accessible Media Player Installer.exe](https://github.com/demon-of-fire/accessible-media-player/releases/latest)

This installer is the Windows app package. Download it, run it, and follow the installer prompts.
