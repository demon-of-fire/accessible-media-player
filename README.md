# Accessible Media Player

A fully featured accessible media player built with Electron.

## Download

Installable Windows builds are intended to live on the GitHub Releases page, matching the simple release-first format used by the Among Us accessibility mod repo.

## Development

1. Install dependencies with `npm install`.
2. Start the app with `npm start`.
3. Build the Windows installer with `npm run build`.

## Source

This repository contains the application source. Generated builds, installers, dependency folders, and Electron Builder output are intentionally excluded from git history.
