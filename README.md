# Accessible Media Player

A fully featured, screen-reader friendly media player built with Electron. Plays video and audio, with an NVDA-friendly interface, keyboard shortcuts, playlists, subtitles, picture-in-picture, audio equalizer, read-aloud subtitles, lyrics, bookmarks, and more.

## Download

[Download Accessible Media Player Installer.exe](https://github.com/demon-of-fire/accessible-media-player/releases/latest)

This installer is the Windows app package. Download it, run it, and follow the installer prompts.

## Highlights

- Built for screen readers: spoken status messages, labelled controls, focus that never gets lost, and a skip link to the playback controls.
- Everything works from the keyboard, and shortcuts use Ctrl so screen readers pass them through. Press `F1` in the app for the full list, or `Ctrl+Shift+P` to search every command.
- Press `Ctrl+A` to hear the current time and `Ctrl+W` to hear what is playing.
- Subtitles (`.srt`, `.vtt`) and lyrics (`.lrc`) saved next to a media file with the same name load automatically.
- Virtual surround, 8D, wide stereo, concert hall and headphone comfort sound modes. Press `Ctrl+D` to switch.
- High contrast, large text and colour themes, with your preferences remembered between sessions.

- Plays links from sites such as YouTube, and formats such as AVI, WMV and WMA, using free helper tools it offers to download the first time they are needed.
- Speech boost, skip silence, sound cues, chapters in MKV files, and it remembers your place in every file.
- Also available as a portable version that needs no installing.
